# What's new

## v1.1.0 — 2026-10-21

- Added an interactive terminal app with tabs, filters, previews, sorting, exports, saved searches, and 131 language options.
- Added desktop result context menus and double-click opening, with fixed column headers and full-path tooltips.
- Fixed terminal results arriving in the wrong tab, offscreen selections, repeated folder arguments, and Unicode editing after switching tabs.
- Kept failed file operations visible, updated descendant paths after moves, and required an explicit `y` to confirm permanent deletion.
- Corrected Windows Properties handling and passed filenames directly to the Windows shell when opening files.
- Included desktop, CLI, and terminal executables in the portable Windows x64 ZIP, with dependency notices and SHA-256 checksums.

## v1.0.0 — 2026-10-20

- First public release with desktop and CLI search, 131 language options, adjustable interface scale, and a portable Windows x64 archive.
